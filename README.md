# Solver Version 1

This is my project for developing CFD solver where i'll add more and more methods and langauge and take out results for my research paper publication

Finite Volume Method based CFD solver in Python.

Current Features:
- Structured Cartesian mesh
- Scalar transport framework
- ~~Gauss-Seidel iterative solver~~
- Operative functions such as
  * Divergence
  * Gradient
  * Interpolation added
- Multiple Fields involved
  * Vectors on Faces
  * Scalars on cell nodes
  * Tensor on cell and points

Planned Features:
- SIMPLE
- QUICK
- PISO
- 3D extension
